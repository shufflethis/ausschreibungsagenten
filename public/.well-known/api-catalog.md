# Ausschreibungsagenten API Catalog

Canonical RFC 9727 catalog: https://www.ausschreibungsagenten.de/.well-known/api-catalog

The catalog links the same-origin OpenAPI 3.1 specification, MCP server card and human developer documentation. Public previews are anonymous; higher limits and protected operations use the API-key process described in `/auth.md`.

- OpenAPI: `/openapi.json`
- MCP Server Card: `/.well-known/mcp/server-card.json`
- Developer documentation: `/entwickler`
- Agent Instructions: `/agents.md`
