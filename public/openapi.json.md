# Ausschreibungsagenten OpenAPI

Canonical specification: https://www.ausschreibungsagenten.de/openapi.json

The OpenAPI 3.1 document describes tender search, source status, country coverage, company profiles, API-key management, A2A and MCP. Every operation has a stable operationId and description. The same-origin document adds production servers, security defaults, licensing, sandbox metadata and the deprecation policy.

Human documentation: https://www.ausschreibungsagenten.de/entwickler

Authentication: https://www.ausschreibungsagenten.de/auth.md
